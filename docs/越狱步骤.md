# SpringBreak 越狱逐步清单（PW4 / 固件 5.18.1.1.1）

官方说明：https://kindlemodding.org/jailbreaking/SpringBreak/

本机工具已下载到：`tools/springbreak/`（或解压后的同名目录）。

## 开始前

- [ ] Kindle 电量 > 50%，最好插着电
- [ ] 确认固件仍是 **5.18.1.1.1**（设置 → 设备选项 → 设备信息）
- [ ] Kindle 已登录亚马逊账号
- [ ] USB 线能传文件（不要用不支持数据的充电线）
- [ ] Mac 上关掉可能自动打开 Kindle 盘符的干扰操作；准备好聊天窗口，一步一步来

## 第 1 步：飞行模式并重启

1. Kindle 下拉菜单 → 打开 **飞行模式**
2. 长按电源键 → **重启**
3. 重启完成后，确认仍是飞行模式

告诉我：「第 1 步完成」

## 第 2 步：用 USB 连上 Mac

1. 用线把 Kindle 接到 Mac
2. 屏幕应进入「U 盘 / 传文件」状态（不要出现只能充电、或带很大 Disconnect 的异常界面）
3. Finder 侧边栏应出现 Kindle 磁盘

告诉我：「已连接」，我会在本机检测并帮你跑 SpringBreak。

## 第 3 步：Mac 上跑 SpringBreak（可代跑）

我会在终端执行官网推荐命令（或本地 `tools` 里的 `springbreak-darwin`），你按屏幕提示：

1. 选择列表里你的 Kindle 编号，回车
2. 等待写入大量填充文件（可能较久，不要拔线）

完成后告诉我。

## 第 4 步：打开商店触发越狱

1. **拔掉** USB
2. 在主页点 **商店（Store）** 图标
3. 若提示关闭飞行模式 → **关闭飞行模式并连 Wi‑Fi**
4. 等待 SpringBreak 页面与文字出现（可能有无关报错，可忽略）
5. 看到成功提示后，等系统界面恢复到主页

告诉我：「越狱成功界面已出现」或把屏幕上看到的文字发我。

## 第 5 步：清理填充文件（必须）

1. 再插上 USB
2. 告诉我「已再连接」——我会再跑一次 SpringBreak 做 **cleanup**
3. 不做这步会导致以后开机极慢

## 第 6 步：hotfix 与 kterm

按官网 What's Next 安装 hotfix，再装 kterm。装好后我们再部署 `kindle/run.sh` 看板脚本。

## 我无法替你按的键

飞行模式、重启、点商店、确认弹窗 —— 只能你在 Kindle 上点；Mac 侧检测磁盘、运行 SpringBreak、拷贝脚本我可以代劳。
